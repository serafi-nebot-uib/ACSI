# Sistema utilizado

- Macbook Air 2022, CPU Apple M2 8-core, RAM 16GB
- VMWare Fusion 13.6.3
    - Ubuntu 22.04.5 LTS
    - 30GB disco
    - 12GB RAM (máximo recomendado por VMWare Fusion)
    - 8 cores
    - Sysbench 0.4.12

## Configuración del sistema

El ordenador en el que he realizado toda la práctica es un Macbook Air 2022 con CPU Apple M2 de 8 núcleos y 16GB de RAM. He utilizado VMWare Fusion 13.6.3 para cear una máquina virtual con 30GB de disco, 12GB de RAM y 8 núcleos de CPU.

Debido a que me he encontrado con muchos problemas para instalar Ubuntu 16.04, la versión preferible para realizar esta práctica porque se puede instalar una versión de sysbench < 1.0 directamente, he decidio instalar Ubuntu 22.04.5 y instalar una versión de sysbench < 1.0 manualmente.

## Instalación Sysbench

Debido a que no he encontrado ningúna versión de Sysbench < 1.0 precompilada para Ubuntu 22.04.5, he descargado el código fuente de la versión 0.4.12, que es la más reciente antes de la 1.0, del [repositorio de paquetes de Fedora](https://src.fedoraproject.org/repo/pkgs/sysbench) y he seguido los siguientes pasos.

### Instalar dependencias

```bash
sudo apt install make automake libtool pkg-config libaio-dev autoconf libtool-bin libtool
```

### Descarga código fuente

```bash
mkdir install
cd install
wget https://src.fedoraproject.org/repo/pkgs/sysbench/sysbench-0.4.12.tar.gz/3a6d54fdd3fe002328e4458206392b9d/sysbench-0.4.12.tar.gz
tar -xvf sysbench-0.4.12.tar.gz
cd sysbench-0.4.12
```

### Actualizar la versión de config.guess y config.sub para que ./configure funcione

```bash
wget -O config/config.guess 'https://git.savannah.gnu.org/gitweb/?p=config.git;a=blob_plain;f=config.guess;hb=HEAD'
wget -O config/config.sub 'https://git.savannah.gnu.org/gitweb/?p=config.git;a=blob_plain;f=config.sub'
```

### Compilar a partir del código fuente

```bash
./autogen.sh
autoupdate
./configure --without-mysql # se obvia mysql para evitar instalar dependencias; no se necesita para los tests de carga de CPU
sudo make LIBTOOL=/usr/bin/libtool
sudo make LIBTOOL=/usr/bin/libtool install
```

### Instalar el ejecutable generado en el sistema

```bash
sudo cp sysbench/sysbench /usr/local/bin/
sudo chmod +x /usr/local/bin/sysbench
sysbench --version
```
