## Configuración del sistema

El ordenador en el que he realizado toda la práctica es un Macbook Air 2022 con CPU Apple M2 de 8 núcleos y 16GB de RAM. He utilizado VMWare Fusion 13.6.3 para cear una máquina virtual con 30GB de disco, 12GB de RAM y 8 núcleos de CPU.

Debido a que me he encontrado con muchos problemas para instalar Ubuntu 16.04, la versión preferible para realizar esta práctica porque se puede instalar una versión de sysbench < 1.0 directamente, he decidio instalar Ubuntu 22.04.5 y instalar una versión de sysbench < 1.0 manualmente.

## Instalación Sysbench

Debido a que no he encontrado ningúna versión de Sysbench < 1.0 precompilada para Ubuntu 22.04.5, he descargado el código fuente de la versión 0.4.12, que es la más reciente antes de la 1.0, del [repositorio de paquetes de Fedora](https://src.fedoraproject.org/repo/pkgs/sysbench) y he seguido los siguientes pasos.

### Instalar dependencias

```bash
sudo apt install make automake libtool pkg-config libaio-dev autoconf libtool-bin libtool
```

### Descarga código fuente

```bash
mkdir install
cd install
wget https://src.fedoraproject.org/repo/pkgs/sysbench/sysbench-0.4.12.tar.gz/3a6d54fdd3fe002328e4458206392b9d/sysbench-0.4.12.tar.gz
tar -xvf sysbench-0.4.12.tar.gz
cd sysbench-0.4.12
```

### Actualizar la versión de config.guess y config.sub para que ./configure funcione

```bash
wget -O config/config.guess 'https://git.savannah.gnu.org/gitweb/?p=config.git;a=blob_plain;f=config.guess;hb=HEAD'
wget -O config/config.sub 'https://git.savannah.gnu.org/gitweb/?p=config.git;a=blob_plain;f=config.sub'
```

### Compilar a partir del código fuente

```bash
./autogen.sh
autoupdate
./configure --without-mysql # se obvia mysql para evitar instalar dependencias; no se necesita para los tests de carga de CPU
sudo make LIBTOOL=/usr/bin/libtool
sudo make LIBTOOL=/usr/bin/libtool install
```

### Instalar el ejecutable generado en el sistema

```bash
sudo cp sysbench/sysbench /usr/local/bin/
sudo chmod +x /usr/local/bin/sysbench
sysbench --version
```

## CPU

Para monitorizar el porcentaje de uso de la CPU se ha utilizado el la primera línea del archivo `/proc/stat`:

```bash
$ cat /proc/stat | head -n 1
cpu  12070 86 2074 516794 445 0 40 0 0 0`
```

Que indica la cantidad de [*jiffies*](https://litux.nl/mirror/kerneldevelopment/0672327201/ch10lev1sec3.html) de CPU desde que se ha encendido el sistema con el siguiente formato: `cpu [user] [nice] [system] [idle] [iowait] [irq] [softirq] [steal] [guest] [guest_nice]`. Esto significa que el "tiempo" total de CPU es la suma de todos los campos, "tiempo" que la CPU ha estado sin hacer nada es la suma de los campos `idle` y `iowait`, y la utilización real de la CPU es la resta entre el tiempo total y el tiempo sin hacer nada.

Debido a que estos campos representan el acumulado hasta el momento, se debe calcular la diferencia de cada uno de los campos para cada intervalo de monitorización. De tal forma, se puede calcular el porcentaje de utilización total de la CPU:

$$
U_{CPU} = \frac{(T_i - T_{i-1}) - (I_i - I_{i-1})}{T_i - T_{i-1}} \cdot 100 = 1 - \frac{I_i - I_{i-1}}{T_i - T_{i-1}} \cdot 100
$$

siendo $T_i$ la suma de todos los campos y $I_i$ la suma de los campos `idle` y `iowait`, en el instante $i$.

## RAM

Para monitorizar la utilización de la memoria RAM se han utilizado las dos primeras líneas del archivo `/proc/meminfo`:


```bash
$ cat /proc/meminfo | head -n 2
MemTotal:       12227312 kB
MemFree:        10558068 kB
```

Que indican la memoria total del sistema y la memoria libre, respectivamente, en kilobytes ($1 \mathit{KB} = 2^{10} \mathit{B}$). A diferencia del archivo `/proc/stat`, son valores absolutos y no es necesario calcular las diferencias entre intervalos de monitorización. Se puede calcular el procentaje de utilización directamente:

$$
U_{RAM} = \frac{M_{TOTAL} - M_{FREE}}{M_{TOTAL}} \cdot 100
$$

siendo $M_{TOTAL}$ la memoria total del sistema y $M_{FREE}$ la memoria libre.

## Automatización

Para automatizar el proceso de ejecutar una carga específica, lanzar los monitores, pararlos cuando la carga termine, y recuperar todos los datos generados se ha hecho con varias funciones de Python.

```python
from __future__ import annotations

import re
import time
import subprocess
from pathlib import Path

TIME_UNITS = { "h": 60*60, "m": 60, "s": 1, "ms": 1/1000, "us": 1/1000000 }

def cpu() -> tuple[float, float]:
  with Path("/proc/stat").open("r") as f:
    # field order: [user] [nice] [system] [idle] [iowait] [irq] [softirq] [steal] [guest] [guest_nice]
    fields = list(map(int, f.readline().strip().split()[1:]))
    return sum(fields), fields[3] + fields[4]

def mem() -> tuple[float, float]:
  with Path("/proc/meminfo").open("r") as f:
    return float(f.readline().split()[1].split()[0]) * 1024, float(f.readline().split()[1].split()[0]) * 1024

def load(*, num_threads: int, max_prime: int, monitor_interval: float, print_overhead: int = False) -> tuple[float, list[float], list[float]]:
  cmd = ["sysbench", f"--num-threads={num_threads}", "--test=cpu", f"--cpu-max-prime={max_prime}", "run"]
  cpu_prev, time_start = cpu(), time.time()
  proc = subprocess.Popen(cmd, stdout=subprocess.PIPE, stderr=subprocess.PIPE) # noqa: S603

  cpu_usage, mem_usage = [], []
  while True:
    time_total = time.time() - time_start
    sleep_time = monitor_interval - time_total
    if print_overhead: print(f"monitor time: {time_total:.6f}; monitor interval: {monitor_interval:.6f}; sleep_time: {sleep_time:.6f}")
    time.sleep(sleep_time)
    if proc.poll() is not None: break
    time_start = time.time()

    cpu_current = cpu()
    total_diff, idle_diff = (a - b for a, b in zip(cpu_current, cpu_prev))
    cpu_usage.append((1 - idle_diff / total_diff) * 100 if total_diff > 0 else 0)
    cpu_prev = cpu_current

    mem_total, mem_free = mem()
    mem_usage.append((1 - mem_free / mem_total) * 100)

  stdout, *_ = proc.communicate()
  ptrn = re.compile(r"^\s*(total time:)\s*\b(\d+\.\d+)(h|m|s|ms|us)\b")
  load_time = next(float(p.group(2)) * TIME_UNITS[p.group(3)] for l in stdout.splitlines() if (p := ptrn.search(l.decode())))

  return load_time, cpu_usage, mem_usage, stdout
```
